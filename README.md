# Proctra

An enterprise-grade, privacy-focused online examination proctoring application built with Electron, React, and Vite.

## Features

- **Lockdown Environment**: Kiosk mode, full-screen lockdown, system shortcut prevention, and blur/focus lost detection.
- **Continuous Proctoring**: Periodic webcam snapshot capture, audio monitoring, and local audit event trail.
- **Examiner Overrides**: Secure invigilator dashboard with credential verification (`proctra2026`).
- **Comprehensive Score & Integrity Report**: Transparent candidate score report, detailed question review, and recorded proctoring log.

## Getting Started

### Development
```bash
# Start Vite dev server & Electron window
npm run dev
npm start
```

### Production Build
```bash
npm run build
```
